# 0.1.0

Initial community release candidate.

- Organize papers as collapsible file explorer entries with configurable components.
- Import PDFs and Markdown files into categorized paper folders.
- Configure component opening order, file naming order, templates, and split viewing.
- Prefer the metadata title when naming a paper, falling back to component filenames.
- Look up Crossref and arXiv metadata.
- Connect optional PaddleOCR-compatible OCR and chat-completions-compatible translation services.
- Leave the default OCR service URL empty for new installations.

Desktop only. OCR and translation require separately configured services. Read the README for network use and account or payment requirements.
